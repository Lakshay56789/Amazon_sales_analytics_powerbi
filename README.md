# 📊 Amazon Sales Analytics Dashboard

An interactive Business Intelligence dashboard built using **Python** and **Power BI** to analyze the Amazon Global Sales dataset. The project focuses on data cleaning, preprocessing, modeling, and visualization to uncover key business insights and support data-driven decision-making.

---

## 📌 Overview

This project demonstrates the complete data analytics workflow, starting from raw data preprocessing in Python to creating an interactive Power BI dashboard. The dashboard enables users to explore sales trends, profitability, shipping performance, and regional distribution through dynamic visualizations and KPIs.

---

## 🎯 Objectives

- Clean and preprocess raw sales data
- Handle missing and inconsistent values
- Build an optimized data model
- Design an interactive Power BI dashboard
- Analyze business performance across multiple dimensions
- Generate actionable business insights

## 📊 Dashboard Features

The Power BI dashboard includes:

- 📈 Total Sales KPI
- 💰 Total Profit KPI
- 📦 Total Quantity Sold
- 🚚 Shipping Cost Analysis
- 🌍 Country-wise Sales Analysis
- 🏙️ City-wise Performance
- 📂 Category-wise Revenue
- 📅 Sales Trend Analysis
- 🔍 Interactive Filters & Slicers
- 📉 Drill-down Reports
